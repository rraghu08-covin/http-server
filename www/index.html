Capabilities

What this server can do

⚡

Thread Pool

Every connection is handled by a fixed-size worker pool. No thread-per-connection overhead.

📄

Static File Serving

Serves any file under the document root with correct MIME type detection for 35+ extensions.

📁

Directory Listing

Auto-generated, sortable HTML listing when no index file is present. Toggle with -n.

👤

POSIX Sockets

Raw socket API — bind, listen, accept, recv, send. No libuv, no Boost.Asio.

🛡

Signal Handling

Graceful SIGINT/SIGTERM shutdown. Drains the thread pool and closes the socket cleanly.

🌎

MIME Detection

Extension-to-MIME lookup table covering web, image, font, media, document and source-code types.

Quick Start

Get up and running in seconds

bash
# clone and build
git clone https://github.com/rraghu08-covin/http-server
cd http-server && make

# run on port 8080, serving ./www
./http-server
